# Booking.com 'Enter your details' Form Analysis

## Mandatory Fields
- **First Name**: Input field, required (marked with *).
- **Last Name**: Input field, required (marked with *).
- **Email Address**: Input field, required (marked with *).
- **Country/region**: Dropdown select, required (marked with *).
- **Phone number**: Input field with Country Code dropdown, required (marked with *).

## Optional Fields & Add-ons
- **'Who are you booking for?'**: Radio buttons (optional).
    - Options: "I am the main guest", "Booking is for someone else".
- **'Are you travelling for work?'**: Radio buttons (optional).
    - Options: "Yes", "No".
- **Add-ons (Checkboxes)**:
    - "I’ll need a flight for my trip"
    - "I'm interested in renting a car"
    - "Want to book a taxi or shuttle ride in advance?" (Airport taxi/shuttle)
- **'Special requests'**: Textarea (optional).
- **'Your arrival time'**: Dropdown select (optional).

## Observations
- **Confirm Email**: This field was NOT found on the current page. The email address is entered once with a note "Confirmation email goes to this address".
- **Airport Taxi**: Specifically listed as "Want to book a taxi or shuttle ride in advance?".
- **Car Rental**: Listed as "I'm interested in renting a car".
- **Arrival Time**: Listed as "Add your estimated arrival time" dropdown.
