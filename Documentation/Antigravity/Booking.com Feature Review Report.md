# Booking.com Feature Review Report

## 1. Homepage Features
- **Header Navigation:**
    - Logo (Home redirect)
    - Currency & Language selectors
    - Help/Support center
    - 'List your property' for partners
    - 'Register' and 'Sign in' buttons
- **Main Search Bar:**
    - Destination input ("Where are you going?")
    - Date picker (Calendar view for Check-in/Check-out)
    - Occupancy selector (Adults, Children with age selection, Rooms)
    - 'Search' button
    - Checkbox: "Add flights to my search"
- **Product Navigation:** Tabs for Stays, Flights, Flight + Hotel, Car rentals, Attractions, and Airport taxis.
- **Promotional Content:**
    - 'Offers' section (e.g., Getaway Deals)
    - Value propositions (Free cancellation, 24/7 support, 2M+ properties)
    - Destination suggestions (Trending, Explore)

## 2. Search Results Page Features
- **Filter Sidebar:**
    - Price/Budget range slider
    - Popular filters (Star rating, Breakfast, Property type)
    - Specific categories: Facilities (WiFi, Pool), Room facilities, Neighbourhood, Cancellation policy.
- **Sorting & View Options:**
    - Sort by: Top picks, Price (lowest first), Stars, Review score.
    - Result count (e.g., "500 properties found")
    - 'Show on map' interactive button.
- **Property Listing Cards:**
    - High-quality image preview
    - 'Save' (Heart) icon for wishlists
    - Property Name and Star rating
    - Location details with distance from landmarks/centre
    - Review score badge (Numeric score, text label, and review count)
    - Room type and bed configuration
    - Price summary (Total price, tax info)
    - Benefit tags: 'Free cancellation', 'No prepayment needed', 'Breakfast included'.
    - 'See availability' CTA button.

## 3. Property Details Page Features
- **Gallery & Media:** Large image gallery with thumbnail grid.
- **Property Info:**
    - Descriptive text/overview of the property.
    - 'We Price Match' guarantee badge.
    - Sustainability level info.
    - List of top facilities (icons and text).
- **Booking/Availability Table:**
    - Accommodation type, capacity, price, and booking conditions (cancellation/meals).
    - 'Select amount' dropdown and 'I'll reserve' button.
- **Guest Feedback:**
    - Detailed review score breakdown (Staff, Cleanliness, Comfort, Value, etc.).
    - Searchable review list with guest comments.
- **Surroundings & Rules:**
    - 'What's nearby' (Attractions, Transport, Airports).
    - House rules (Check-in/out times, pets, children, age limits).
    - 'Fine print' for additional property notes.
- **Host Info:** Details about the property manager or host.
